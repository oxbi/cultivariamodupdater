# Cultivaria mod updater

One-click updater for the Cultivaria Forge 1.20.1 modpack (private friends' pack).

**Friends:** download `Cultivaria-Updater.zip` from the Releases page, unzip anywhere, close Minecraft, double-click `Update-Cultivaria.bat`. Run it again after every announced update. It only touches the pack's own mods and configs (old ones are backed up to `.minecraft\cultivaria-update-backup`); your settings, saves, screenshots and own mods stay.

The repo root holds `manifest.json` + `files/` (the current pack) once a release is published.
